# Automation Toolkit

Automation Toolkit is an ongoing learning project where I explore how PowerShell and scripting can be used to simplify recurring IT and administrative tasks.

The goal is not to build a large enterprise system, but to practice practical automation, Windows system understanding and structured problem solving.

## Purpose

This project helps me develop my skills in:

- PowerShell
- Windows automation
- Scripting
- System information
- File and disk management
- Documentation
- Practical problem solving
